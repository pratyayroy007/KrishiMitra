# 🌾 KrishiMitra - Smart Crop Recommendation System

## 📌 Overview

KrushiMitra is a Machine Learning and Flask-based web application that helps farmers identify suitable crops based on agricultural conditions. The project aims to support data-driven farming decisions through an easy-to-use web interface.

---

## 🚀 Features

* Crop Recommendation System
* User-Friendly Web Interface
* Machine Learning-Based Predictions
* Fast and Simple Crop Suggestions
* Agricultural Decision Support
* Responsive Design

⚙️ Installation and Setup

Navigate to Project Folder
cd KrushiMitra
Install Required Libraries
pip install -r requirements.txt
Run the Application
python app.py
Open in Browser

After running the application, open:

http://127.0.0.1:5000

Note: This URL works only on your local machine while the Flask application is running.
